* org-templater

Minimal templating for Org documents.

#+begin_src lisp
(org-templater:render
  :template-path #p"prompt.org"
  :config        config)
#+end_src

Supports:
- ~{{{:key}}}~ interpolation; missing values render as empty strings.
- ~#+begin_when :key [value]~ conditional blocks.
- ~:WHEN: :key [value]~ heading properties applying to the whole subtree.

* Development

#+BEGIN_SRC sh
./script/bootstrap
./script/check
./script/check --fix
#+END_SRC

=./script/check= runs the tests, then checks the source with
[[https://github.com/lambda-symbolics/cheque][cheque]] as =cheque.sexp=
configures it. =--fix= skips the tests and repairs what cheque can repair.
cheque and its tools are development dependencies: =checks/qlfile= lists them,
and the check installs them on first use into =~/.cache/cheque/tools/=.
